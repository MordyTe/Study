# Puzzle games

- State the rule you believe applies before acting on it, then test it with one move.
- Record the grid or board in a note when it is small enough; compare after each move.
- Prefer reversible moves while exploring. Use `remember` for dead ends so you do not repeat them.
- A move that produced `no_observable_change` is probably illegal in this state; do not repeat it.
- Undo and reset controls are worth finding early.
