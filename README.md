# 💰 המדריך המלא: עסקים דיגיטליים להכנסה (חצי-)פסיבית — 2026

> מדריך עבודה אישי שנבנה בסיעור מוחות עם Claude.
> המטרה: לבחור ולבנות עסק דיגיטלי שמייצר הכנסה משמעותית, עם מקסימום אוטומציה מבוססת AI.

## ⚠️ לפני שמתחילים — שתי אמיתות

1. **"הכנסה פסיבית" היא תוצאה, לא נקודת התחלה.** כל עסק עובר: בנייה (עבודה קשה, אפס כסף) → תפעול (עבודה בינונית, כסף מתחיל) → אוטומציה (מעט עבודה, כסף זורם). מי שמוכר "פסיבי מהיום הראשון" מרוויח ממך, לא מהשיטה.
2. **הטיית שורדים.** ברשתות רואים רק את המנצחים. על כל "עשיתי 100K בחודש" יש מאות שנשרו בשקט. המספרים במדריך הזה ריאליים, לא אינסטגרמיים.
