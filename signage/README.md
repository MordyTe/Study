# שילוט דיגיטלי על Raspberry Pi

קופסה אחת מאחורי טלוויזיה = מסך אחד. מנהלים את מה שמוצג מהטלפון: בוחרים תבנית, ממלאים
כמה שדות, לוחצים "פרסום", וזה על המסך תוך כמה שניות.

**מצב:** אב טיפוס. התוכנה נבדקה במחשב (53 בדיקות אוטומטיות, ומעבר מלא על דף הניהול ועל
התצוגה בדפדפן). **ההתקנה על Raspberry Pi אמיתי עוד לא נבדקה.**

## מה יש
- **13 תבניות:** תפריט/מחירון, מבצע, שעות פתיחה, ברוכים הבאים, לוח הודעות, שעון ותאריך
  עברי, זמני שבת, זמני תפילות, זמני היום, תמונה במסך מלא, מצגת תמונות, סרטון, טקסט חופשי.
- **סרטונים:** העלאה מהטלפון (MP4 או WebM, עד 300MB). הסרטון מתנגן עד סופו ואז עוברים
  לשקופית הבאה. אפשר עם קול או בלי.
- **כל גודל מסך:** ה-Pi מזהה את הרזולוציה מהמסך דרך ה-HDMI, והשקופיות מתאימות את עצמן.
  הרזולוציה שזוהתה מוצגת ב"הגדרות".
- **רקעים:** 12 רקעים מובנים (מעברי צבע ודוגמאות שנכתבו כ-CSS לפרויקט הזה, בלי קובצי תמונה
  ובלי זכויות של צד שלישי), או תמונה משלכם כרקע, שמוכהה אוטומטית כדי שהטקסט יישאר קריא.
- **מוזיקת רקע:** שירים שהעליתם (MP3, M4A, OGG, WAV) בלולאה, או רדיו אינטרנטי לפי כתובת
  שידור. כשמוצג סרטון עם קול המוזיקה נעצרת וחוזרת אחריו.
- **הפעלה ראשונה בלי מקלדת:** מחברים לרשת, הכתובת מופיעה על המסך, ובטלפון נפתח אשף של
  שני שלבים (קוד כניסה, פרטי המקום) שמכין סט שקופיות מוכן לפי סוג המקום.
- **תאריך תפוגה ושכפול:** שקופית יכולה לרדת לבד בתאריך שנקבע, ואפשר לשכפל שקופית קיימת.
- **אשף בארבעה שלבים:** סוג המקום ← תבנית ← תוכן וצבעים ← תצוגה מקדימה ופרסום.
- **עריכה:** שינוי תוכן, סדר, משך הצגה, כיבוי זמני, מחיקה.
- **תמונות:** העלאה מהטלפון (גלריה או מצלמה). תמונות גדולות מוקטנות אוטומטית.
- **תזמון:** ימים ושעות לכל שקופית (למשל תפריט בוקר עד 12:00).
- **זמני שבת וזמני היום:** מחושבים על המכשיר לפי העיר, בלי אינטרנט.
- **עובד בלי אינטרנט:** הכול שמור על ה-Pi. צריך רשת ביתית רק כדי לערוך מהטלפון.
- **קוד כניסה:** דף הניהול מוגן בקוד של 4 עד 8 ספרות.

## לנסות על המחשב (בלי Pi)
```bash
cd signage
./run.sh
```
התצוגה: http://localhost:8080 · הניהול: http://localhost:8080/admin

## התקנה על Raspberry Pi 4
1. **צורבים כרטיס:** ב-Raspberry Pi Imager בוחרים "Raspberry Pi OS (64-bit)" עם שולחן
   עבודה. בהגדרות מגדירים שם משתמש, Wi-Fi ואזור זמן `Asia/Jerusalem`.
2. **מחברים** את ה-Pi לטלוויזיה ב-HDMI, מדליקים ומחכים לשולחן העבודה.
3. **מעתיקים את התיקייה `signage`** ל-Pi (למשל עם `git clone` של הריפו), ובטרמינל:
   ```bash
   cd signage
   ./install.sh
   sudo reboot
   ```
4. אחרי ההפעלה המסך מציג **כתובת וקוד QR**. פותחים את הכתובת בטלפון שמחובר לאותה רשת,
   ועוברים את האשף הראשוני.

### מה קורה כשלקוח מקבל מכשיר מוכן
1. מחבר חשמל, HDMI וכבל רשת. השרת עולה לבד עם ההדלקה, עוד לפני שיש רשת.
2. כל עוד אין כתובת, המסך מציג "ממתין לחיבור לרשת". ברגע שהנתב נותן כתובת היא מופיעה
   על המסך תוך כמה שניות, עם קוד QR.
3. הלקוח מקליד את הכתובת בטלפון (רק המספרים, בלי שום תוספת) ומגיע לאשף.
4. אחרי האשף המסך כבר מציג שקופיות. בשתי הדקות הראשונות אחרי כל הדלקה הכתובת נשארת
   בפינת המסך, כדי שאפשר יהיה למצוא אותה שוב.

חיבור ב-Wi-Fi בלי מקלדת עוד לא נתמך: בגרסה הזאת הלקוח מחבר כבל רשת, או שה-Wi-Fi מוגדר
מראש בזמן צריבת הכרטיס.

### אם משהו לא עולה
| מה רואים | מה לבדוק |
|---|---|
| שולחן עבודה רגיל, בלי מסך מלא | `~/signage/kiosk.sh` בטרמינל. אם זה עובד, ההפעלה האוטומטית לא נתפסה בגרסת המערכת שלכם. |
| דף לבן או "לא ניתן להתחבר" | `systemctl status signage` ואחר כך `journalctl -u signage -n 50` |
| הטלפון לא מגיע לדף הניהול | הטלפון וה-Pi באותה רשת? נסו את הכתובת שמופיעה על המסך, לא את ה-QR. |
| עברית מוצגת כריבועים | `sudo apt-get install fonts-noto-core` והפעלה מחדש |
| שעון או זמנים לא נכונים | אזור הזמן של ה-Pi: `sudo timedatectl set-timezone Asia/Jerusalem` |
| שכחתם את קוד הכניסה | מוחקים את הקוד (התוכן נשאר): `sqlite3 data/signage.db "DELETE FROM settings WHERE key LIKE 'pin_%'; DELETE FROM sessions;"` ונכנסים שוב לדף הניהול. |

## עיצוב מ-Canva
**בלי חיבור (עובד תמיד):** ב-Canva יוצרים עיצוב 1920×1080, מורידים כ-PNG או JPG לטלפון,
ומעלים ל"תמונה במסך מלא" או כרקע ("רקע" ← "תמונה שלי").

**חיבור ישיר (ניסיוני):** כל בעל מסך מחבר את חשבון ה-Canva שלו ומייבא עיצובים ישר לספריית
התמונות ("תמונות" ← "ייבוא מ-Canva"). הקוד נכתב לפי התיעוד הציבורי של Canva ונבדק רק מול
Canva מדומה בבדיקות. **הוא עוד לא רץ מול Canva האמיתית.**

הגדרה חד-פעמית:
1. ב-[Canva Developer Portal](https://www.canva.com/developers/) יוצרים Integration ציבורי.
2. מסמנים את ההרשאות `design:meta:read` ו-`design:content:read`.
3. רושמים כתובת חזרה: `http://127.0.0.1/api/canva/callback` (על ה-Pi; בהרצה על מחשב עם
   `run.sh` הכתובת היא עם `:8080`). הכתובת המדויקת מופיעה ב"הגדרות" ← "Canva".
4. מעתיקים את ה-Client ID וה-Client secret לדף הניהול: "הגדרות" ← "Canva".
5. לוחצים "חיבור חשבון Canva" **מדפדפן על המכשיר שמריץ את המסך** (בכתובת
   `http://127.0.0.1/admin`), ומאשרים ב-Canva.

מגבלות החיבור הישיר:
- Canva מקבלת רק כתובות חזרה שנרשמו מראש, וכתובת ברשת ביתית (192.168…) אינה אפשרית. לכן
  את החיבור עצמו עושים על המכשיר. אחרי שחובר, מייבאים מכל טלפון ברשת.
- כדי שלקוחות יחברו חשבון מהטלפון שלהם צריך כתובת HTTPS ציבורית שלנו (משתנה הסביבה
  `SIGNAGE_CANVA_REDIRECT`) ואישור של Canva ל-Integration. עד האישור הוא במצב טיוטה לבדיקות.
- ה-Client secret נשמר על המכשיר. במוצר אמיתי הוא צריך לשבת בשרת שלנו ולא אצל הלקוח.
- נדרש אינטרנט בזמן הייבוא. התמונות שיובאו נשמרות על המכשיר וממשיכות לעבוד בלעדיו.

## להוסיף תבנית
יוצרים תיקייה ב-`templates/` עם שני קבצים, ומפעילים מחדש את השרת. לא צריך לגעת בקוד.
- `template.json`: שם, תיאור, קטגוריות (`business` / `lobby` / `synagogue` / `general`)
  ורשימת שדות. סוגי שדות: `text`, `textarea`, `number`, `select`, `image`, `images`,
  `video`, `rows`.
- `template.html`: תבנית Jinja שמרחיבה את `_base.html`. השדות זמינים כ-`d.<key>`, ובנוסף
  `place`, `city`, `hebrew_date`, `day_name`, `zmanim`, `shabbat`. גדלים ביחידות `vh`/`vw`
  כדי שיתאימו לכל מסך.

הדרך הקלה היא להעתיק תבנית קיימת ולשנות.

## מגבלות שכדאי לדעת
- **זמני היום מקורבים** (דיוק של דקה-שתיים, בלי התחשבות בגובה). לפני שתולים בבית כנסת,
  להשוות ללוח מודפס. הדלקת נרות: 40 דקות בירושלים ובפתח תקווה, 30 בחיפה, 20 בשאר הערים.
- **מסך אחד לכל Pi.** אין עדיין ניהול של כמה מסכים ממקום אחד, ואין גישה מחוץ לרשת המקומית.
- **רשת מהימנה בלבד:** כל מי שברשת יכול לראות את התצוגה, ודף הניהול מוגן רק בקוד קצר.
  לא לחשוף את המכשיר לאינטרנט.
- **תפריט צפוף:** עד כ-10 פריטים לשקופית נשאר קריא מרחוק. מעבר לזה עדיף לפצל לשתי שקופיות.
- **סרטונים מוצגים כמו שהם,** בלי המרה. נגינת MP4 על ה-Pi עצמו עוד לא נבדקה; אם סרטון
  לא מתנגן, המערכת מדלגת לשקופית הבאה אחרי כמה שניות. מומלץ עד 1080p.
- **מסך לאורך (טלוויזיה עומדת) עוד לא נתמך:** העיצובים בנויים למסך לרוחב.
- **Spotify לא נתמך.** תנאי השימוש של Spotify לא מתירים השמעה בעסק או במקום ציבורי, והנגן
  שלהם לדפדפן דורש רכיב הגנת תוכן שלא קיים בדפדפן של ה-Pi. לשימוש ביתי אפשר להתקין על
  ה-Pi את `raspotify`, שהופך אותו לרמקול שבוחרים מאפליקציית Spotify (דורש Premium).
- **רישיון להשמעת מוזיקה:** השמעה בעסק או במקום ציבורי דורשת בדרך כלל רישיון מארגוני
  הזכויות, גם לרדיו. זו אחריות בעל המקום.
- **כתובות רדיו:** המערכת לא מגיעה עם רשימת תחנות. מזינים כתובת שידור ישיר של התחנה.
- אין התראות פיקוד העורף.
