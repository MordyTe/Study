# מה הבעלים עושה פעם אחת

הסוכנים בונים את הכלים; כדי שהכלים יימכרו ושהכסף יגיע אליך, צריך חשבונות על שם של אדם.
אף אחד מהצעדים לא דורש עורך דין. סדר מומלץ:

## 1. חשבון מפתח ב‑Apify (הכי חשוב — שם מתקבלים התשלומים)
1. https://console.apify.com → הרשמה (מייל רגיל מספיק).
2. Settings → Monetization → "Become a developer" — ממלאים פרטי תשלום (PayPal או העברה
   בנקאית) ואימות זהות.
3. יוצרים **API token** (Settings → Integrations) ושומרים אותו — תעביר לי אותו בצ'אט רק
   כשנגיע לשלב הפרסום, ואני אשמור אותו מחוץ לריפו.

## 2. מארקטפלייס MCP (אפשר אחרי הראשון)
- https://smithery.ai — התחברות עם GitHub, הוספת שרת, הגדרת תמחור.
- ייתכן שיידרש אימות זהות לקבלת תשלומים.

## 3. מייל עסקי + דומיין (לא חובה בהתחלה)
- דומיין כמו `makor.tools` / `makor-data.com` — הסוכנים יציעו זמינות; אתה רוכש (~$10–15/שנה).
- מייל לחשבונות (Gmail/Workspace).

## 4. מס (כשיש הכנסה ראשונה)
- פתיחת עוסק פטור/מורשה מול רו"ח — רק כשמגיע הדולר הראשון. לא לפני.

## מה הסוכנים מבקשים ממך
כל מה שצריך החלטה או כסף מופיע ב"צריך את ההחלטה שלך" בדוח המנכ"ל, וב‑`state/inbox.json`.
עונים בצ'אט — ואני מעדכן את התיבה. החברה ממשיכה מהמקום שבו עצרה.
