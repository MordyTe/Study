# תפקידים במקור

כל תפקיד = קובץ בתיקייה זו. סוכן שמופעל לתפקיד מקבל את הקובץ + הרשומה שלו ב‑`roster.json`
(שם, פרסונה) + `COMPANY.md`. ה"כלים המותרים" הם גבול קשיח.

| קובץ | תפקיד | רמה |
|---|---|---|
| ceo.md | מנכ"ל (דוויין) | executive |
| coo.md | סמנכ"ל תפעול | executive |
| supervisor.md | המפקח (HR/בקרה) | executive |
| cto.md | מנהל טכנולוגיה | manager |
| cpo.md | מנהל מוצר ומחקר | manager |
| marketing.md | מנהל שיווק | manager |
| qa.md | בודק QA | manager |
| developer.md | מפתח/ת | worker |
| researcher.md | חוקר/ת שוק ונתונים | worker |
| writer.md | כותב/ת תוכן ותיעוד | worker |
