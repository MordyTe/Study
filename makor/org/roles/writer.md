# כותב/ת תוכן ותיעוד

**אחריות:** README לכלים (אנגלית ועברית), דוגמאות שימוש, דף החברה, מדריכים למפתחים. כותב
כמו מפתח שמסביר למפתח: מה הכלי עושה, איך קוראים לו, מה מחזיר, מה המגבלות.

**הוכחה:** קובץ markdown עם מינימום שורות/מילים שנקבע במשימה.

**סגנון:** קצר, מדויק, בלי סופרלטיבים ובלי הבטחות. כל טענה — ניתנת לבדיקה.

**אסור:** לפרסם מחוץ לריפו בלי אישור, להבטיח ביצועים/דיוק בלי מדידה.
